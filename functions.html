Python Functions

What is a Function?

A function is a block of code which only runs when it is called. You can pass data, known as parameters, into a function. A function can return data as a result.

# Defining a function
def greet(name):
    """This function greets the person passed in as parameter"""
    print("Hello, " + name + "!")

# Calling a function
greet("Alice")  # Output: Hello, Alice!

Function Arguments

Information can be passed into functions as arguments. Arguments are specified after the function name, inside the parentheses.

# Function with multiple arguments
def describe_pet(animal_type, pet_name):
    """Display information about a pet."""
    print(f"I have a {animal_type}.")
    print(f"My {animal_type}'s name is {pet_name.title()}.")

describe_pet('hamster', 'harry')

Return Values

Functions can return values to the caller. Use the return statement to send a value back.

# Function with return value
def square(number):
    """Return the square of a number."""
    return number * number

result = square(4)
print(result)  # Output: 16
